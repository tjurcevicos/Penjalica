# Penjalica

2D platformska igra izrađena pomoću HTML-a, CSS-a i JavaScripta.

===== Funkcionalnosti =====

- Nasumično generirane platforme
- Skupljanje jagoda 🍓
- Bodovi prema visini i skupljenim predmetima
- Tri života ❤️
- Odbrojavanje vremena ⏱️
- Jagode dodaju dodatno vrijeme
- Nova igra nakon Game Over ekrana

===== Kontrole =====

⬅️ Strelica lijevo
➡️ Strelica desno

Lik automatski skače kada doskoči na platformu.
